# Упрощённый режим igedits

В репозитории теперь есть два варианта запуска.

## Рекомендуемый: отдельное лёгкое приложение

Для личного использования без аккаунтов, базы, Redis, Instagram и платёжных функций используйте:

```bash
cp simple_app/.env.example .env
docker compose -f docker-compose.standalone.yml up -d --build
```

Откройте `http://IP_СЕРВЕРА:3000`.

Этот режим самостоятельно выполняет весь цикл:

- загрузка видео;
- локальное распознавание русского языка через faster-whisper;
- выбор фрагментов встроенным алгоритмом или внешней LLM;
- вертикальный рендер 9:16;
- наложение русских субтитров;
- скачивание отдельных MP4 и общего ZIP.

Подробности находятся в `SIMPLE_STANDALONE_RU.md`.

## Совместимый режим исходного приложения

Файл `docker-compose.simple.yml` оставлен как CPU-only override для исходного интерфейса igedits. Он закрывает внутренние порты и отключает часть необязательных интеграций, но сохраняет исходную сложную архитектуру.

Для VPS 2 vCPU / 4 GB рекомендуется именно отдельный `docker-compose.standalone.yml`.
