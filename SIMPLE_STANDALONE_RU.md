# igedits Simple — локальный аналог OpusClip

Это отдельный облегчённый режим проекта. Он не требует регистрации, PostgreSQL, Redis, Instagram, Stripe или AssemblyAI.

## Что делает

1. Принимает видео через браузер.
2. Локально распознаёт русскую речь через `faster-whisper`.
3. Выбирает 1–5 законченных фрагментов:
   - бесплатно встроенной эвристикой;
   - либо точнее через любую OpenAI-совместимую LLM.
4. FFmpeg вырезает фрагменты, переводит их в 9:16 и накладывает русские субтитры.
5. Даёт скачать каждый MP4 и общий ZIP.

LLM не получает видео или звук. Ей отправляется только текст расшифровки с таймкодами. Если LLM не настроена или вернула ошибку, приложение автоматически использует бесплатный локальный алгоритм.

## Запуск

```bash
git checkout agent/simple-local-clips
cp simple_app/.env.example .env
docker compose -f docker-compose.standalone.yml up -d --build
```

Открыть:

```text
http://IP_СЕРВЕРА:3000
```

При первом запуске контейнер скачает модель Whisper. Она сохраняется в Docker volume и повторно не загружается.

## VPS 2 vCPU / 4 GB

Рекомендуемые параметры уже выставлены:

```env
WHISPER_MODEL=small
WHISPER_COMPUTE_TYPE=int8
WHISPER_CPU_THREADS=2
FFMPEG_PRESET=veryfast
MAX_CLIPS=5
```

На сервере желательно создать 4 GB swap. Одновременно следует обрабатывать только одно видео.

## Подключение платной LLM

Пример OpenAI-совместимого API:

```env
LLM_API_URL=https://api.openai.com/v1
LLM_API_KEY=ваш_ключ
LLM_MODEL=gpt-4.1-mini
```

Можно указать другой совместимый сервис. В запрос уходит только русский текст с таймкодами, поэтому стоимость анализа обычно небольшая.

Без этих переменных система полностью работает локально, но выбор лучших моментов будет проще и менее точным.

## Ограничения текущей версии

- вертикальное кадрирование пока центральное, без слежения за лицом;
- задания хранятся в памяти процесса, а готовые файлы — в Docker volume;
- нет авторизации, поэтому порт 3000 не следует публиковать без reverse proxy и защиты;
- полный запуск и обработка реального видео должны быть проверены непосредственно на целевом VPS.

## Команды

Логи:

```bash
docker compose -f docker-compose.standalone.yml logs -f
```

Остановка:

```bash

```

```bash
docker compose -f docker-compose.standalone.yml down -v
```
